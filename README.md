# Mecánica de Distribuciones

Este repositorio contiene un libro sobre mecánica de distribuciones. El documento se actualiza de forma automática según voy añadiendo nuevo material.

> [!WARNING]
> El documento se actualiza de forma posterior al desarrollo de la teoría. Es decir, puedo haber desarrollado a mano algún punto o tema y no haberlo detallado aún en el documento. 

Cualquier comentario, issue, push ... es completamente bienvenido.
